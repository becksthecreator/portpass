# Briefs

A brief is the written request a piece of PortPass work starts from: why, what to build in which order, the rules it could break, what to report back, and when it is done.

- **Written with `/brief`.** In Claude Code, type `/brief` followed by the request in plain words. The command (`.claude/commands/brief.md`) turns it into a brief in the house format and saves it here as `<NN>_<slug>.md`, numbered after the highest one in this folder.
- **They also live in the Beckford HQ project.** The Claude project "The Beckford HQ" keeps the briefs too, in its `ClaudeCode_Queue_Sept29/` folder, with the Handbook. Briefs up to 19 were written there; the first one saved here is numbered 20.

The rules every brief works within are in `CLAUDE.md` at the top of the repo.
